Konfigurasi Database Cloud (Firebase) & Publikasi

Cara Menghubungkan ke Proyek Firebase Pribadi Madrasah:

  1. Buka console.firebase.google.com → Buat Proyek Baru → Aktifkan Authentication (Email/Password & Anonymous) dan Cloud Firestore.
  2. Salin objek firebaseConfig dari Project Settings Anda lalu tempelkan di bawah ini.
  3. Unggah file HTML tunggal ini ke Netlify Drop atau Vercel untuk langsung mendapatkan tautan web online gratis.
